# Tejas Kasbekar - Portfolio Website

A professional portfolio website built with HTML, CSS, and JavaScript featuring a black/green theme, animations, and responsive design.

## Features
- Modern black/green color scheme
- Fully responsive design (mobile, tablet, desktop)
- Smooth animations and transitions
- Interactive contact form with validation
- Downloadable resume PDF
- Scroll animations and hover effects
- Clean, professional layout
